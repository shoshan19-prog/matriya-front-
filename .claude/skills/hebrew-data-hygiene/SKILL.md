# היגיינת נתונים בעברית

הלקחים מהעבודה על רשימות האדריכלים (3,584 רשומות מ-4 מקורות → mailing-list-merged): רוב ה"כפילויות" בעברית אינן זהות-מחרוזת — הן זהות-אחרי-נרמול.

## 1. נרמול שמות (אנשים, חברות, פרויקטים)

סדר פעולות קבוע לפני כל השוואה:
1. ‏trim + צמצום רווחים כפולים + הסרת ניקוד (‏`unicodedata.normalize('NFKD')` וסינון combining marks).
2. אחידות גרשיים: ‏`״`→`"`, ‏`׳`→`'` (מקור כפילויות מרכזי: מנכ"ל/מנכ״ל).
3. הסרת תוארים ותחיליות: אדר'/אדריכל/אינג'/ד"ר/משרד — לשדה role, לא לשם.
4. וריאציות כתיב מוכרות — טבלת aliases ידנית, לא ניחוש: אלקונין/אלקולין · סירני/סרני · הצריחים ×3 (טבלת name_norm במסד). כל התאמה fuzzy (‏Levenshtein ≤2 על שם מנורמל) — **מועמדת** לאיחוד, מאושרת ידנית; לא ממזגים אוטומטית.

```python
import unicodedata, re
def norm_he(s):
    s = unicodedata.normalize('NFKD', str(s or ''))
    s = ''.join(c for c in s if not unicodedata.combining(c))
    s = s.replace('״','"').replace('׳',"'")
    s = re.sub(r"^(אדר'|אדריכל(ית)?|אינג'|ד\"ר|משרד)\s+", '', s.strip())
    return re.sub(r'\s+', ' ', s)
```

## 2. כתובות
- פיצול לשדות לפני נרמול: רחוב · מספר · עיר. לא משווים כתובת כמחרוזת אחת.
- אחידות: רח'/רחוב → רחוב · שד'/שדרות → שדרות · ת"א/תל אביב-יפו → תל אביב.
- עיר מאומתת מול רשימת יישובים רשמית (למ"ס) — כל מה שלא מזוהה → עמודת review, לא ניחוש.
- לגיאוקוד (project.lat/lon): לגאוקד את הצורה המנורמלת; ציון confidence נשמר; מתחת לסף — ידני.

## 3. טלפונים
```python
def norm_phone(p):
    d = re.sub(r'\D', '', str(p or ''))
    if d.startswith('972'): d = '0' + d[3:]
    if len(d) == 9 and d[0] != '0': d = '0' + d      # אקסל בלע את האפס המוביל
    return d if re.fullmatch(r'0(5\d|[2-4,8-9])\d{7}', d) else None
```
אקסל הורס טלפונים בשתי דרכים: מוחק אפס מוביל (מספר) והופך תצוגה ב-RTL. לייבא עמודות טלפון כ-**טקסט** תמיד.

## 4. אימיילים וכפילויות
- מפתח הייחוד: ‏`lower(email)` — בדיוק כמו האינדקס במסד (audience_member). ‏trim, להסיר נקודה סופית, לתקן טעויות נפוצות (‏gmial→gmail, ‏.con→.com) רק עם סימון "תוקן".
- אימות MX לפני שליחה (חסם דומיינים מתים — 47% בשכבה ב'!): תוצאה נשמרת ב-mx_status: ‏mx_valid / mx_invalid / hold. ‏invalid לא נמחק — מסומן.
- דה-דופ בין מקורות: מפתח ראשי email; חסר email → (שם מנורמל + טלפון מנורמל). שומרים source לכל רשומה — כפילות בין מקורות היא מידע (מופיע גם בכנס וגם ברשימה = חם יותר).

## 5. RTL באקסל
- הדבקת עברית+מספרים יוצרת תצוגה הפוכה — הנתון תקין, התצוגה שקרית. לבדוק ערך אמיתי ב-formula bar, לא בעין.
- תווי כיווניות נסתרים (RLM ‏U+200F, ‏LRM ‏U+200E, ‏RLE/PDF) נכנסים מהעתקות — לנקות: ‏`re.sub(r'[‎‏‪-‮]', '', s)` — הם שוברים השוואות ומיונים.
- ‏CSV עם עברית: לשמור UTF-8-BOM (‏`utf-8-sig`), אחרת אקסל מציג ג'יבריש.
- מיון עברי: ‏sort רגיל ממיין לפי unicode — מספיק לעברית, אבל רק **אחרי** ניקוי תווי כיווניות.
