# WordPress — כללי עבודה בטוחים

## חוק היסוד
**לעולם לא `status=publish` ישירות.** כל יצירה/עדכון נעשים כ-`draft` (או `pending`), והפרסום עצמו קורה רק אחרי אישור דוד בתחנת האישור (הכרעה 9 במסמך-האב). זה מקביל ל-`content_asset.state`: ‏draft → pending_approval → approved → **רק אז** published.

## סדר פעולות מחייב לכל עריכה

1. **גיבוי לפני נגיעה:** ‏`GET /wp-json/wp/v2/posts/{id}?context=edit` → לשמור את ה-JSON המלא (title/content/excerpt/meta) לקובץ מקומי עם timestamp. אין עריכה בלי עותק שממנו אפשר לשחזר.
2. **עריכה כ-draft:** ‏`POST /wp-json/wp/v2/posts/{id}` עם ‏`{"status":"draft", ...}`. עמוד חי שחייב להישאר חי? יוצרים **טיוטה חדשה** או revision — לא דורסים את החי.
3. **אימות:** ‏GET חוזר + השוואת שדות. לרשום ב-log מה שוּנה.
4. **פרסום:** רק בפקודת אישור מפורשת מדוד, כפעולה נפרדת.

## Auth
- ‏**Application Passwords** (מובנה מ-WP 5.6): ‏Users → Profile → Application Passwords. ‏Basic auth: ‏`user:app-password` על HTTPS בלבד.
- לא להשתמש בסיסמת החשבון הראשית בסקריפטים; מפתח נפרד לכל כלי, עם שם ברור — קל לבטל.
- אחרי אירוע האבטחה (F-006): כל Application Password שקדם ל-8.2026 — לבטל וליצור חדש.

## עברית ו-RTL
- ודא ‏`Content-Type: application/json; charset=utf-8`; לשלוח JSON, לא form-encoded (עברית נשברת).
- ‏**Slug:** ‏WP ייצר percent-encoding מכוער מעברית. לקבוע ידנית slug לטיני קצר: ‏`beit-abud-akko` ולא ‏`%D7%91%D7%99%D7%AA...`. זה גם קריטי ל-SEO.
- ערכת נושא: לוודא `rtl.css` נטען; בתוכן — לא לערבב כיווניות inline; מספרים ומונחים לועזיים ב-`<span dir="ltr">`.
- ‏Excerpt ו-alt-text למדיה — בעברית, נכתבים ידנית (לא auto).

## מדיה
- העלאה: ‏`POST /wp-json/wp/v2/media` עם ‏`Content-Disposition: attachment; filename="..."` — שם קובץ **לטיני** (עברית בשם קובץ שוברת CDN-ים). ה-title/alt בעברית בשדות המטא.
- לפני העלאת תמונת פרויקט: לוודא `media.rights=owned` במסד הישויות. ‏unknown = לא מעלים (זכויות יוצרים).

## מה אסור בשום מצב
- מחיקת עמוד/פוסט (‏`DELETE`) — לעולם. במקום: ‏draft + תיוג לבדיקה.
- התקנת/עדכון plugins דרך API או שינוי theme — רק ידנית ע"י דוד.
- ‏Bulk-עדכון של יותר מ-5 עמודים בפעולה אחת בלי אישור נפרד.
- לגעת בעמודים שאינם קשורים למשימה ("אם כבר אני שם...").

## הקשר
גישת הניהול לאתר היא חסם C2 במפת הפרויקט. כשהיא נפתחת — הסקיל הזה הוא החוזה: המערכת מקבלת כוח פרסום, והבלמים האלה הם מה שמונע ממנה לשבור אתר חי.
